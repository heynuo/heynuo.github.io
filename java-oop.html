Java OOP Tutorial: Classes, Objects & Inheritance

👤 HeyNuo 📅 June 2, 2026 🔄 Updated Sep 28, 2026 ☕ Java ⏱ 6 min read

Object-oriented programming (OOP) is the heart of Java. It turns complex code into modular, reusable, and scalable blueprints. Whether you're a beginner or refreshing fundamentals, this crash course covers encapsulation, inheritance, polymorphism, and abstraction — with real-world Java examples.

1. Encapsulation — data hiding

Encapsulation bundles data (fields) and methods inside a class while restricting direct access. Use private fields and public getters/setters.

☕ BankAccount.java 
public class BankAccount {
    private double balance;
    
    public void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    public double getBalance() { return balance; }
}

// Execution:
BankAccount acc = new BankAccount();
acc.deposit(250.0);
System.out.println("Balance: $" + acc.getBalance());
// acc.balance = 500; // ❌ Compile Error: balance has private access in BankAccount
⚡ JVM Console Output
$ java BankAccount Balance: $250.0 [Encapsulation]: Direct field mutation blocked. State remains protected.

2. Inheritance — reusability

Child classes inherit fields and methods from a parent class using extends. Reduces code duplication.

☕ VehicleInheritance.java 
class Vehicle {
    String brand = "Tesla";
    void honk() { System.out.println("Beep beep!"); }
}

class Car extends Vehicle {
    int wheels = 4;
    void drive() { System.out.println(brand + " is cruising with " + wheels + " wheels."); }
}

// Execution:
Car myCar = new Car();
myCar.honk();
myCar.drive();
⚡ JVM Console Output
$ java VehicleInheritance Beep beep! Tesla is cruising with 4 wheels. [Inheritance]: Car accessed inherited 'brand' field and 'honk()' method seamlessly.

3. Polymorphism — many forms

One interface, multiple implementations: method overloading (compile-time) and method overriding (runtime dynamic dispatch).

☕ AnimalPolymorphism.java 
class Animal { 
    void sound() { System.out.println("Some generic animal sound"); } 
}

class Cat extends Animal { 
    @Override 
    void sound() { System.out.println("Meow! 🐱"); } // Method Overriding (Dynamic dispatch)

    // Method Overloading (Compile-time polymorphism)
    void sound(int repeat) {
        for (int i = 0; i < repeat; i++) System.out.print("Meow! 🐱 ");
        System.out.println();
    }
}

class Dog extends Animal { 
    @Override 
    void sound() { System.out.println("Woof! 🐶"); } 
}

// Execution:
Animal a1 = new Cat();
Animal a2 = new Dog();
a1.sound(); // Runtime dynamic dispatch to Cat.sound()
a2.sound(); // Runtime dynamic dispatch to Dog.sound()

Cat myCat = new Cat();
myCat.sound(2); // Compile-time method overloading invoked
⚡ JVM Console Output
$ java AnimalPolymorphism Meow! 🐱 Woof! 🐶 Meow! 🐱 Meow! 🐱 [Polymorphism]: Dynamic method table resolved overriding; parameter signature resolved overloading.

4. Abstraction — hide complexity

Use abstract classes or interfaces to define contracts without prescribing implementation details.

🎯 Pro Tip: Always favor composition over inheritance when possible, and remember: “Program to an interface, not an implementation.” This keeps your code flexible.
☕ PaymentContract.java (Interface Abstraction) 
// 1. Contract specification (What, not How)
interface PaymentGateway {
    void process(double amount);
}

// 2. Concrete implementation hidden from caller
class StripeGateway implements PaymentGateway {
    @Override
    public void process(double amount) {
        System.out.println("💳 Processed $" + amount + " securely via Stripe API");
    }
}

// 3. Client code couples exclusively to interface contract
PaymentGateway gateway = new StripeGateway();
gateway.process(99.0);
⚡ JVM Console Output
$ java PaymentContract 💳 Processed $99.0 securely via Stripe API [Abstraction]: Client code interacts exclusively with PaymentGateway contract without implementation coupling.

5. Enterprise Case Study: Polymorphic Payroll Service

☕ PayrollService.java 
abstract class Employee {
    String name;
    Employee(String name) { this.name = name; }
    abstract double calculateSalary();
}

class FullTimeEmployee extends Employee {
    double baseSalary = 50000;
    FullTimeEmployee(String name) { super(name); }
    @Override
    double calculateSalary() { return baseSalary; }
}

class InternEmployee extends Employee {
    double stipend = 15000;
    InternEmployee(String name) { super(name); }
    @Override
    double calculateSalary() { return stipend; }
}

// Polymorphic Payroll Processing in Spring Boot:
List<Employee> staff = List.of(new FullTimeEmployee("Sarah"), new InternEmployee("Alex"));
staff.forEach(e -> System.out.println(e.name + ": $" + e.calculateSalary()));
⚡ JVM Console Output
$ java PayrollService Sarah: $50000.0 Alex: $15000.0 [Abstraction & Polymorphism]: Payroll service interacts exclusively with the Employee abstraction.

Now you can process any Employee polymorphically — a foundational pattern used throughout enterprise Spring architectures.

6. Hands-On Coding Challenge: Immutable Value Object

In enterprise Java architecture, mutating object state directly creates subtle bugs and race conditions. A resilient pattern is the Immutable Value Object.

🎯 Challenge Prompt: Design a Money value object that stores a BigDecimal amount and a 3-letter currency code (e.g. "USD"). Requirements:
  • All fields must be private final.
  • Constructor must validate that amount is not null/negative and currency is not null, empty, or blank.
  • Provide an add(Money other) method that returns a brand new Money instance after verifying identical currency.
  • Override equals() and hashCode() to enforce structural equality rather than reference identity.
☕ MoneyValueObject.java (Interactive Exercise) 
import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.Objects;

public final class Money {
    private final BigDecimal amount;
    private final String currency;

    public Money(BigDecimal amount, String currency) {
        Objects.requireNonNull(amount, "Amount must not be null");
        if (amount.compareTo(BigDecimal.ZERO) < 0) {
            throw new IllegalArgumentException("Amount cannot be negative: " + amount);
        }
        if (currency == null || currency.isBlank()) {
            throw new IllegalArgumentException("Currency must not be null or blank");
        }
        this.amount = amount.setScale(2, RoundingMode.HALF_UP);
        this.currency = currency.trim().toUpperCase();
    }

    public Money add(Money other) {
        Objects.requireNonNull(other, "Cannot add null Money");
        if (!this.currency.equalsIgnoreCase(other.currency)) {
            throw new IllegalArgumentException("Mismatched currency: " + this.currency + " vs " + other.currency);
        }
        return new Money(this.amount.add(other.amount), this.currency);
    }

    public BigDecimal getAmount() { return amount; }
    public String getCurrency() { return currency; }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Money money = (Money) o;
        return amount.compareTo(money.amount) == 0 && currency.equals(money.currency);
    }

    @Override
    public int hashCode() {
        return Objects.hash(amount.stripTrailingZeros(), currency);
    }

    @Override
    public String toString() {
        return amount + " " + currency;
    }
}

// Execution & Invariant Verification:
Money salary = new Money(new BigDecimal("4500.00"), "USD");
Money bonus = new Money(new BigDecimal("500.00"), "USD");
Money total = salary.add(bonus);

System.out.println("Original salary intact: " + salary);
System.out.println("Computed total compensation: " + total);
System.out.println("Equals check (same amount & currency): " + salary.equals(new Money(new BigDecimal("4500.00"), "USD")));
⚡ JVM Console Output
$ java Money Original salary intact: 4500.00 USD Computed total compensation: 5000.00 USD Equals check (same amount & currency): true [Value Object]: Thread-safe, immutable BigDecimal representation with structural equality.
