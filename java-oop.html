Java OOP Crash Course

📅 June 2, 2026 ☕ Java ⏱ 8 min read

Object-oriented programming (OOP) is the heart of Java. It turns complex code into modular, reusable, and scalable blueprints. Whether you're a beginner or refreshing fundamentals, this crash course covers encapsulation, inheritance, polymorphism, and abstraction — with real-world Java examples.

💡 Why OOP matters — modern frameworks (Spring, Hibernate) and large-scale systems are built on OOP. Mastering it makes you a fluent Java developer.

1. Encapsulation — data hiding

Encapsulation bundles data (fields) and methods inside a class while restricting direct access. Use private fields and public getters/setters.

public class BankAccount {
    private double balance;
    
    public void deposit(double amount) {
        if(amount > 0) balance += amount;
    }
    public double getBalance() { return balance; }
}

2. Inheritance — reusability

Child classes inherit fields and methods from a parent class using extends. Reduces duplication.

class Vehicle {
    String brand;
    void honk() { System.out.println("Beep!"); }
}
class Car extends Vehicle {
    int wheels = 4;
}

3. Polymorphism — many forms

One interface, multiple implementations: method overloading (compile-time) and overriding (runtime).

class Animal { void sound() { System.out.println("some sound"); } }
class Cat extends Animal { 
    @Override 
    void sound() { System.out.println("Meow"); } 
}
// Animal a = new Cat(); a.sound() → Meow

4. Abstraction — hide complexity

Use abstract classes or interfaces to define contracts. Example: interface Payment { void pay(); } implemented by CreditCardPayment, PayPalPayment.

🎯 Pro Tip: Always favor composition over inheritance when possible, and remember: “Program to an interface, not an implementation.” This keeps your code flexible.

Real-World Example: Employee Management

abstract class Employee {
    abstract double calculateSalary();
}
class FullTime extends Employee {
    double salary = 50000;
    double calculateSalary() { return salary; }
}
class Intern extends Employee {
    double stipend = 15000;
    double calculateSalary() { return stipend; }
}

Now you can process any Employee polymorphically — a core pattern in Spring services.
