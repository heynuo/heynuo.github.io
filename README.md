# My Website

A simple website project with multiple pages and basic styling.

## Project Structure

```
my-website/
│
├── index.html          # Home page
├── about.html          # About page
├── contact.html        # Contact page
│
├── css/
│   └── style.css       # Main stylesheet
│
├── js/
│   └── script.js       # JavaScript functionality
│
├── images/             # Image assets folder
│
├── sitemap.xml         # XML sitemap for search engines
├── robots.txt          # Robots configuration
└── README.md           # This file
```

## Features

- Responsive navigation menu
- Multiple pages (Home, About, Contact)
- Contact form
- CSS styling
- SEO-friendly structure with sitemap and robots.txt

## Getting Started

1. Open `index.html` in your web browser to view the website
2. Customize the content in the HTML files
3. Modify styles in `css/style.css`
4. Add interactivity in `js/script.js`

## Development

To test the website locally:
- Use a local server (e.g., Python's http.server or Node's http-server)
- Or simply open the HTML files directly in your browser
